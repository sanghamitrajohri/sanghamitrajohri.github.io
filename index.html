I'm an AI Inference Engineer at Armada, where I build and scale real-time computer vision and multimodal inference systems on NVIDIA GPUs. In production, I've scaled vision pipelines from 10 to over 100 concurrent video streams on A100s at twice the throughput. I focus on where performance is actually lost, such as memory bandwidth, CPU–GPU synchronization and batching, in both cloud and edge environments.

I'm always glad to connect with people working on AI systems, inference and multimodal AI.

Projects

RecoverIQ: Cost-Aware Recovery for AI Coding Agents

2026 · demoed at AI Tinkerers · code / project page / case study

When a coding agent fails, RecoverIQ uses TypeSafe's Jev to pick the cheapest fix that will work (retry, switch model, restore a checkpoint, ask a human, or stop) instead of blindly retrying. On 108 live runs with Claude it reached 42.9 clean fixes per dollar, against 25.3 for hand-written rules.

KV-Caching and Profiling for Transformer Inference

2024 · University of Washington, Seattle · case study

Implemented KV-caching in nanoGPT for a 2.0× faster per-token generation, and profiled the Llama decode layer (Flash-Attention, MLPs, GEMMs) across batch sizes 1–64 and sequence lengths up to 16K with Nsight Systems, finding a 3× speedup for batched inference.

GPU-Accelerated Matrix Multiplication in CUDA

University of Washington, Seattle · code

A parallel matrix multiplication written from scratch in CUDA and C++, mapping matrix tiles to thread blocks and using shared-memory tiling to cut redundant global memory reads.
