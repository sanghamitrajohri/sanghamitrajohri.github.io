GPU-Accelerated Matrix Multiplication

Independent project, University of Washington

CUDA · C++

Problem

Matrix multiplication is the computational core of nearly every deep learning workload, and a naive CPU implementation leaves almost all of a GPU's parallelism on the table. I wanted to understand, from first principles, what it actually takes to make matrix multiplication fast on a GPU — the layer PyTorch normally hides.

Architecture

What I Built

  • Implemented a parallel matrix multiplication application in CUDA and C++.
  • Mapped matrix tiles to GPU thread blocks to exploit the GPU's parallel execution model instead of a sequential CPU loop.
  • Used shared-memory tiling to cut down on redundant global memory reads across threads in the same block.

Lessons

Writing the kernel by hand — thread indexing, shared-memory tiles, bank conflicts — made every abstraction PyTorch normally hides feel concrete. It's a lot easier to reason about why a GPU kernel is slow in production once you've had to write one from scratch.
